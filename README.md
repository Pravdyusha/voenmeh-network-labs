### Практические работы по дисциплине «Сети ЭВМ и телекоммуникации»

### Практическая работа №1 – Изучение сетевых утилит и уровней модели OSI

- Изучение основных сетевых утилит Windows/Linux: `ipconfig`/`ifconfig`, `ping`, `netstat`, `arp`, `tracert`/`traceroute`, `netsh`
- Определение уровня модели OSI для каждой утилиты
- Работа с различными параметрами команд (2–3 параметра для каждой утилиты)
- Анализ и подробное описание вывода информации (IP-адреса, MAC-адреса, таблица маршрутизации, ARP-таблица, TCP-соединения, правила брандмауэра и др.)

**Отчёт** → [practical-1.pdf](docs/practical-1.pdf)

### Практическая работа №2 – Сканирование сети с помощью утилиты NMAP

- Установка утилиты NMAP
- Определение адреса локальной сети
- Сканирование сети на наличие активных хостов (`nmap -sn`)
- Сканирование всех возможных портов на активных хостах (`nmap -p-`)
- Определение типа операционной системы удалённых устройств (`nmap -O`, `nmap -Pn -O`)

**Отчёт** → [practical-2.pdf](docs/practical-2.pdf)

### Практическая работа №3 – Анализ и перехват сетевого трафика с помощью TCPDUMP

- Установка утилиты `tcpdump` в Linux
- Просмотр списка доступных сетевых интерфейсов (`tcpdump -D`)
- Перехват и анализ ARP-пакетов
- Перехват и анализ ICMP-пакетов
- Фильтрация и перехват TCP-пакетов
- Анализ TCP-трафика с отключением разрешения имён (`-n`)

**Отчёт** → [practical-3.pdf](docs/practical-3.pdf)
